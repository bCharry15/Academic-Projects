PARA APLICAR LOS CAMBIOS Y SIMULAR:
1. Si miROM.mif esta abierto en un editor, recarguelo; no guarde una version vieja sobre la nueva.
2. Abra PROYECTO_INTEGRADO\PROYECTO_TOP.qpf de esta misma carpeta en Quartus.
3. Ejecute Processing > Start Compilation y espere a que termine sin errores.
4. Abra PROYECTO_INTEGRADO\SIMULACION_COMPLETA.vwf.
5. Ejecute Simulation > Run Functional Simulation desde el inicio, con el reset incluido.
6. Muestre ACC y ROM_OUT en hexadecimal. Observe ACC despues de cada flanco ascendente de PULSO.
No basta con abrir resultados anteriores: es necesario volver a compilar y simular.
Si movio el proyecto y el editor conserva una ruta vieja, seleccione el VWF actual en Simulation Settings.

Para volver al programa original, use la opcion 3 del configurador y compile/simule de nuevo.
Reset reinicia la ejecucion; no restaura la ROM original.
